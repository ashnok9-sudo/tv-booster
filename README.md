# ⚡ TV Booster & Cooler (for Android TV)

A lightweight, zero-configuration 1-click RAM cleaner and CPU cooler designed specifically for budget Android TV boxes and sticks.

---

### Features
* **Zero Complex Setup:** No Wireless ADB, no developer pairing codes, no IP ports required.
* **TV Remote Friendly:** Big buttons with high-contrast D-pad focus indicator for standard TV remotes.
* **1-Click Boost & Cool:** Closes background bloatware and frees RAM to prevent TV boxes from overheating and randomly rebooting.
* **🚀 Boost & Launch Nuvio:** Automatically frees memory, kills background apps, and launches Nuvio directly, giving Nuvio 100% of the TV box's hardware resources!

---

### How to Build on GitHub (Free Automated Cloud Build)
1. Push this folder to a new GitHub repository (or upload the files on github.com).
2. Go to the **Actions** tab on GitHub.
3. The **"Build Android TV Booster APK"** workflow will automatically run and compile the `.apk`.
4. Click on the finished run and download **`TV-Booster-Cooler-APK`** directly!
